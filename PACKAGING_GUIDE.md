# Guía para crear un ejecutable de Windows

## Requisitos
- Node.js instalado
- NPM instalado

## Instrucciones
1. **Instalar dependencias**:
   ```bash
   npm install
   ```

2. **Empaquetar la aplicación**:
   Ejecuta el siguiente comando:
   ```bash
   npm run package-win
   ```
   Esto generará un archivo ejecutable en la carpeta `dist`.

---

¡Tu aplicación está lista para distribuirse en Windows!
